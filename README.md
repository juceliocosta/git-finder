# git-finder

Aplicação desenvolvida em React.js para buscar e visualizar e favoritar repositórios de usuários do GitHub.

## 🧠 O que aprendi

- Manipulação de arrays com `filter`, `find` e `map` para gestão de estado.

- Lógica de renderização condicional para Alternância entre componentes.

- Implementação de containers flexbox para criar interfaces com layouts dinâmicos

- Tratamento de dados assíncronos e IDs únicos da API do GitHub.
